# 芳乃桌宠 1.3.1 高清转头版（Windows x64）

独立桌宠，沿用芳乃 Q 版动画。新版只保留宠物、临时提示和设置；对话与任务操作均回到 Codex 原生窗口。

## 高清素材

本版使用内置 imagegen 重绘的非像素风 Q 版。源图按三组绘制，每组 2×2、每格 627×627；规范透明边缘与统一脚底位置后，导出 12 张 576×624 透明关键姿态。原动画每帧为 192×208，新单帧边长为原来的 3 倍。

待机、左右移动、招手、跳跃、失败、等待、工作和完成九种状态沿用高清关键姿态。1.3.1 使用八方向完整人物图和正面姿态，鼠标移动时切换转头、抬头、低头和视线，屏幕远处同样生效，运行任务时也能跟随。跟随时直接显示对应方向的完整高清人物，不切分头部与身体，也不叠加整个人物倾斜或平移。鼠标静止约 3 秒后恢复任务动画；Windows 关闭界面动画时停止跟随。旧 v2 精灵图仅保留为兼容资源。

八个方向和正面均显示独立完整人物图，仅统一尺寸与脚底位置；输出均为 576×624。12 张原关键姿态的源单元为 627×627。新增方向使用两张 1205×1305 的 2×2 原图，单格 602×652，原生宽高均超过 480。它使用关键姿态和方向帧，并非每种动作的全部帧都分别重绘。

本仓库的 `assets/hq/` 保存程序实际使用的高清图组，`绘图提示词.txt` 保存绘图说明。程序显示大小沿用你的原设置；提高素材分辨率不会自动把桌宠窗口放大。
## 使用

完整解压后运行 `YoshinoPet.exe`，右键芳乃或托盘可打开设置、退出。需要 Windows 10/11 x64、.NET Framework 4.8、已登录的 Codex CLI，以及注册了 `codex://` 链接的 Codex 桌面应用。请先确认本机具备这些运行环境。

| 操作 | 默认快捷键 / 行为 |
| --- | --- |
| 新建 Work | 点击芳乃或 Ctrl+Alt+Space：直接打开 Codex 新建输入框，在原生窗口输入。 |
| 截图并新建 Work | Ctrl+Alt+S：截取当前前台窗口，复制为图片，打开 Codex 新建输入框并粘贴，留给你确认发送。 |
| 显示 / 隐藏 | Ctrl+Alt+Y，或右键菜单。 |
| 额度 / credits | 鼠标放在芳乃上查看，移开后收起；可移到额度气泡上继续阅读。仅显示额度时不再显示“芳乃 · Codex 额度”标题。 |
| 最近动作 | 检测到新动作后显示约 6 秒，保留最近 3 条。点击动作气泡可回到对应 Codex 会话。 |
| 移动 | 左键拖动芳乃，自动记住位置。 |

## 状态显示

约每秒检查一次本机 Codex 活动记录，同时兼容旧版调用记录和新版分页的命令、文件修改记录。识别后显示如“执行中 dotnet build”“已执行 …”“编辑中 Core.cs +17 -5”“已编辑 …”；可读取到错误返回时标为“返回错误”。新版任务即使开始标记已超出日志尾部，也会根据更新的回合事件恢复运行状态。套餐用量变化、相同记录重复扫描不会重新唤出任务气泡。首次启动静默读取已有历史。

新增任务、回合开始、工具调用与返回、进度文字、完成/失败等新动作会更新气泡。没有新动作时，即使任务仍运行，气泡也会收起；芳乃仍保留对应工作动画。

文件名和增删行数来自可解析的 `apply_patch` 内容。通过脚本改文件、动态生成的命令或无法解析的工具格式，只显示可确认的命令/工具信息，不猜测文件差异。工具返回与任务完成分别表示相应调用和整个任务已结束。多条工具被封装为一次调用时，错误提示可能对应这组调用。

这不是 Codex 内部实时事件流：通常延迟约 1 秒，还受日志落盘、接口响应影响。旧版/导入会话可能只有任务状态而没有具体动作。状态读取不完整或连接断开时保持桌宠可见。

## 自动隐藏与额度

启用自动隐藏后，前台窗口最大化或覆盖全屏，且没有运行/等待输入任务、扫描状态完整且新鲜时隐藏。新动作气泡和快捷唤起会短暂保持可见。手动隐藏优先；再次按显隐键恢复。

额度气泡显示套餐窗口剩余百分比、额外 credits、重置时间和刷新时间。后台约每 60 秒刷新，悬停时也会按缓存时间请求更新。缺失数据为“未知”；刷新失败时保留带时间的缓存。初次连接先读取任务，额度网络请求不会延后首轮任务读取。

## 截图与原生窗口

截图优先按窗口句柄抓取；若目标不支持，只有目标仍在前台时才尝试屏幕截取。前台变化则停止该次截取。截图期间隐藏桌宠覆盖层。

截图会覆盖剪贴板内容。打开 Codex 后只在确认前台属于 Codex、且快捷键修饰键已松开时尝试 Ctrl+V。若 Windows 焦点限制或启动延迟导致无法粘贴，图片保留在剪贴板，托盘提示在原生输入框手动 Ctrl+V。不会自动按发送键。

## 设置与数据

设置可修改：自动隐藏、新动作简报、悬停额度、大小、工作目录、CLI 路径、三个快捷键的最后一个键、开机启动。模型、文件权限、审批和对话管理使用 Codex 自身设置。

配置、日志和截图位于 `%LOCALAPPDATA%\YoshinoPet`；Codex 历史与登录沿用现有 `CODEX_HOME`。状态与额度使用本机 App Server 的只读查询；本版本不通过 App Server 发起、续接或停止任务。

默认新 Work 目录为 `Documents\Codex\芳乃Work`。如原生 Pets 同时显示，可用 Codex 的 `/pet` 关闭原生宠物。

## 构建与验证

源码包内执行 `build.ps1`，使用系统 .NET Framework C# 编译器，无 NuGet 依赖。

```powershell
.\build.ps1
.\build\YoshinoPet.exe --self-test C:\Temp\YoshinoTests
.\build\YoshinoPet.exe --integration-test C:\Temp\YoshinoTests
.\build\YoshinoPet.exe --ui-test C:\Temp\YoshinoTests
```

界面测试前退出正式桌宠，避免热键冲突；测试会操作自己的受控窗口和剪贴板。集成测试只读取现有登录、额度和任务，不运行模型请求。测试范围见 `验证说明.md`。
